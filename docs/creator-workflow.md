# Creator workflow

## Outcome

A creator produces a validated source directory that can render across multiple clients without client-specific code.

## Workflow

1. Write a short visual brief, ownership statement, intended content rating, and commercial-use choice.
2. Generate a style board before individual UI assets.
3. Fill both semantic palettes and verify contrast in light and dark modes.
4. Read the slot catalog and generate only the selected standardized locations.
5. Keep one character identity reference and reuse it for idle, thinking, tool, success, and error states.
6. Review, regenerate, or edit individual locations without replacing approved work.
7. Run `dsh-skin validate <directory>` and fix every reported issue.
8. Preview through one or more client adapters, then submit the skin directory for registry review.

Generated artwork is never published automatically. The creator remains the final reviewer and is responsible for likeness, trademark, copyrighted-character, licensing, and disclosure decisions.
